Firmware compiler

Add your Prophet VS banks and wave files. This page builds an FM-1 firmware image on this device. Nothing is sent to a server.

1. Add files

Program dump, wave dump, a 64KB ROM or both 32KB ROM halves, WAV cycles named with a slot number, or a zip of those. Later files replace a cycle you already added, so a saved wave dump wins over the copy stored in the ROM.

    4. Send it to the FM-1

    Use Chrome or Edge on a computer. Switch the FM-1 on and connect a USB data cable to the USB-C port beside the power switch. Close other apps that use MIDI. The install takes about two minutes. Leave the cable in until this page says the FM-1 is back. If the screen stays on UPDATE MODE, press Send again.

    iPad Safari cannot do this step. Download vsfm.fwsc, copy it to a computer, open this page in Chrome or Edge there, and choose that file.

    Skiff (vsfm, FM-1_700) and LOOM-VS (loom-vs.fwsc, FM-1_1100) share the same update path. You can install one over the other directly — you do not need to return to factory first. Factory restore is here if you want stock V15, or if you are coming from M-VAVE's "Open" / community firmware (that one only accepts V15).

    5. Back to factory firmware (V15)

    This writes M-VAVE's official FM-1 V15 over whatever is running (Skiff, LOOM-VS, or safe mode). Your custom projects may be lost. The file is checked in the browser and is never uploaded to a server.

    1. Download M-VAVE's FM-1 V15: FM-1.fwsc (also listed on m-vave.com/download).
    2. Choose that unmodified file below. The page checks its size and SHA-256.
    3. Connect the FM-1 by USB and press Install stock firmware.

    On the instrument

    1. After Send finishes, the FM-1 restarts on this firmware. The same file also opens in the FM-1 emulator.
    2. Knob 1 moves the mix left and right. Knob 2 moves it down and up. 64 is the middle. The mix envelope travels from there, and the knobs offset it.
    3. Knob 3 is cutoff. Knob 4 is resonance. Both follow the original 0–99 range.
    4. ENV opens the amplifier, then the filter, then the mix. Each one has the five rates, the levels, the loop and the repeat. Release fades away instead of staying loud for the whole time. Hold MIDI CC 66 while the note ends to use rate 4A.
    5. LFO opens the two oscillators. Shape, rate and amount are on the first row. The rows after that choose pitch, filter, mix and pan. SELECT moves between rows.
    6. Each of the eight voices keeps its own pan. Pressure, velocity and the key open the filter, move the mix and change the envelope the way the patch stored them. The filter envelope can also sweep the pitch. Chorus rate and depth follow the patch. Split and double use the linked program, detune and delay.
    7. The patch arpeggiator is arp mode VS. Loading a preset does not turn the arp on. Choose VS on the arp page.
    8. Turn the presets encoder, or open Save and choose Presets. Set the engine to Vector. Build again with this page if the pans, the modulators, the chorus rate, split or the patch arp are missing. Glide, unison and rate 4A already work on an older bank.

    Slots 0–8 keep nine original cycles until a file replaces them. Wave 127 is noise. This image leaves out the piano, flute, and sax sample sets, and the slice breaks, so the sampled drum kits fit. The sequencer and the arpeggiator stay.
